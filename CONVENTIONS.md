# Code conventions

## API keys
All API keys must be stored in .env (never hardcoded).
Add new keys to both .env and .env.example.
.env is never committed to version control.

**Language** : All code comments, variable names, function names, and file names must be in English.

**Reason** : Codebase intended to be readable by English-speaking developers.

**Applies to** : All files in this project, including configuration files and data schemas.
